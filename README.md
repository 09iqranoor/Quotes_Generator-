# 📜 Quotes Generator App

A simple and elegant web application that displays a random quote using a free public API. I built this small app while I was learning about API integration in JavaScript.

It was one of my early projects to practice real-world concepts. Although it's simple, I’m proud of it because it helped me understand how APIs work, how to fetch data, and how to dynamically update the DOM.





---

## 🌟 Features

- Fetches random quotes from  https://dummyjson.com/quotes
  
- Clean and modern responsive UI
  
- Refreshes quote on button click
  
- Error handling in case of network issues
